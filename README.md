# regression_analysis

This repo contains code for the regression analysis course I took in semester 2 2021 using `R` and `python`. 

This was forked from my teachers repo. I have changed some of the code to solidify my understanding. 

It covers a very general introduction to econometrics. 

## The content includes:

- Regression Basics & Estimation (OLS)
- Endogeneity and Instrumental Variables (IV)
- Time Series Modelling (static)
- Panel Data (longitudinal data)
- Treatment Effects via Difference-in-differnces (DiD)
- Maximum Likelihood Estimation and Numerical Methods
- Classification Problems (GLMs)
